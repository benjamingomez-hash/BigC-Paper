Plugin independiente para **Paper 26.2 / Java 25**.

Una sola descarga: **Armas-Legendarias-Final.zip**, con los cuatro archivos finales originales:

- `LegendaryWeapons-Final.jar`
- `legendary-weapons-java.zip`
- `config.yml`
- `LEEME.txt`

Incluye las cinco armas, el pack con tamaños corregidos y animaciones desactivadas por defecto. Para instalar, detené Paper, reemplazá el JAR anterior por `LegendaryWeapons-Final.jar` y conservá `plugins/LegendaryWeapons` con sus niveles y datos. Seguí el LEEME incluido; para otros equipos hay que configurar una URL del pack accesible o distribuir el pack manualmente.

Los archivos se publican sin cambios. [Seis análisis de Windows Defender sin detecciones](https://github.com/benjamingomez-hash/BigC-Paper/actions/runs/41224205520), con protección en tiempo real y nube activas, sin exclusiones.
