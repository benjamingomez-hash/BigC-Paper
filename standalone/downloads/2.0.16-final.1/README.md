# LegendaryWeapons 2.0.16-final.1

**[Descargar ZIP final](https://github.com/benjamingomez-hash/BigC-Paper/releases/download/legendary-weapons-2.0.16-final.1/Armas-Legendarias-Final.zip)** ·
[Publicación en GitHub](https://github.com/benjamingomez-hash/BigC-Paper/releases/tag/legendary-weapons-2.0.16-final.1).

Los cuatro archivos originales se publican sin cambios. El JAR declara la versión
`2.0.16-final.1`, Paper 26.2 y Java 25. Incluye el mismo pack y la misma configuración
que los entregados por separado. Las animaciones están desactivadas en esa configuración.

- `Armas-Legendarias-Final.zip`: los cuatro archivos originales juntos.
- `LegendaryWeapons-Final.jar`: plugin terminado por el usuario.
- `legendary-weapons-java.zip`: pack con `pack.mcmeta` en la raíz.
- `config.yml`: configuración aportada.
- `LEEME.txt`: instrucciones originales.
- `SHA256SUMS.txt`: integridad de los originales y del ZIP conjunto.

Este JAR no se reconstruyó desde las fuentes 2.0.16 del repositorio. Los cambios
compilados del usuario y sus fuentes son entregas distintas; no se atribuyen a
este binario las pruebas anteriores del código fuente.

analizó estos archivos exactos sin ejecutarlos ni reconstruirlos: **seis análisis

tiempo real y nube activas, sin exclusiones.
