DupeRestore 1.1.0 — Paper 26.2 / Java 25

Implementación reconstruida desde las fuentes previas, con API pública de Paper.
El JAR maneja el hilo. TNT, alfombras, raíles y ganchos usan la configuración
oficial de Paper. El plugin consulta esas opciones, sin modificarlas.

INSTALACIÓN
1. Detené Paper.
2. En config/paper-global.yml, dentro de unsupported-settings, activá:

   allow-piston-duplication: true
   skip-tripwire-hook-placement-validation: true

   Editá las dos claves existentes. Conservá el resto del archivo y su sección.
   Paper agrupa TNT, alfombras y raíles en la primera opción.
3. Reemplazá el JAR anterior de DupeRestore por DupeRestore-1.1.0.jar en plugins.
4. Iniciá Paper y consultá /duperestore status como operador o desde la consola.

HILO
Un bloque anegado (waterlogged), como una trampilla o escalera, debe soltar agua
directamente hacia un hilo conectado entre dos ganchos enfrentados.
Cae el hilo normal y se repone al tick siguiente si la línea sigue válida y el
origen continúa anegado. Produce mientras siga saliendo agua de ese bloque.
Agua común y corrientes intermedias no activan la reposición. Dejá salida hacia
abajo para que el agua no arrastre los ganchos. Podés recoger los drops con tolvas.

CONFIGURACIÓN
plugins/DupeRestore/config.yml solo controla string-duplication.
/duperestore reload aplica el ajuste del hilo; permiso duperestore.admin.
Las claves antiguas piston-duplication y tripwire-hook-duplication del plugin
se ignoran. Usá las dos opciones de Paper de arriba y reiniciá tras cambiarlas.
Quitar este plugin detiene el dupe de hilo. Para desactivar los dupes nativos,
volvé a false las opciones de Paper y reiniciá.
